# 한자 티어

한자 8급부터 6급까지 누적 300자를 익히는 한자 전용 설치형 웹앱입니다.

**접속:** https://dew978.github.io/hanja-tier/

- 궁서체·수묵 산수화 테마, 뜻·음과 한자어 5개, 한 글자마다 획순대로 두 번 쓰기
- 최초 실력 진단 30문항, 하루 최대 10자, 한 번에 5자
- 5자 중 뜻·음을 모두 맞힌 한자가 4자 이상이면 다음 묶음 해제
- 오늘 묶음을 모두 통과하면 +5·10·15점 (하루 한 번)
- 승급 시험 80% 이상: 최초 승급마다 +100점
- 발전도·절대 진도의 두 가지 순위. 진단·재확인에서 새로 맞힌 한자당 절대 진도 1자와 1점 인정, 중복 제외
- 관리자는 한자 학습 현황·학생 관리·학습 설정만 제공
- GitHub Pages와 전용 Firebase 프로젝트 `hanja-tier` 사용

운영 규칙은 [HANJA_GUIDE.md](HANJA_GUIDE.md), 배포 방법은 [GITHUB_DEPLOY.md](GITHUB_DEPLOY.md)를 참고하세요.

## 학생 일괄 등록

1. 관리자 로그인 → **학생 관리 → 엑셀 양식 다운로드**
2. 양식의 이름·아이디를 작성하고 `.xlsx`로 저장합니다. 초기 비밀번호는 **123456**으로 고정됩니다. 아이디는 영문·숫자·밑줄·하이픈 1~30자이며 앞의 0을 유지합니다.
3. **엑셀로 학생 등록**에서 파일을 선택하고 명단을 확인한 뒤 등록합니다. 빈 행은 제외하고 중복·잘못된 값은 등록 전에 표시합니다. 한 번에 최대 100명, 파일 크기 최대 2MB입니다.
4. 학생은 처음 로그인하면 비밀번호를 변경해야 합니다. 변경 후 로그아웃되며, 새 비밀번호로 다시 로그인해야 학습을 시작할 수 있습니다. 최초 변경 대기 표시는 이 재로그인이 완료될 때 해제됩니다.

한 명씩 등록할 때도 동일한 초기 비밀번호와 첫 로그인 절차를 적용합니다. 기존 학생의 계정·비밀번호·학습 기록은 유지합니다. 등록 도중 오류가 나면 같은 창에서 **남은 학생 다시 등록**을 누르세요. 엑셀 원본은 서버에 업로드하지 않고 브라우저에서 읽습니다.

학생 관리의 **학생 삭제**에서 명단·학습 기록·순위를 함께 삭제할 수 있습니다. 삭제 후 학습 접근이 차단됩니다. 로그인 서비스에 아이디는 남으므로 삭제한 아이디는 재사용할 수 없습니다.

## 로컬 확인

`serve.ps1`을 실행한 뒤 `http://localhost:8767/preview.html`에 접속합니다. 체험 학생으로 자동 로그인되며, 체험 관리자 계정은 `teacher / demo-only`입니다. 모두 가상 데이터입니다. 실제 계정 비밀번호는 소스에 저장하지 않습니다.
